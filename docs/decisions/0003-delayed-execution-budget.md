# ADR-0003：延迟执行状态与市价买单预算

- 状态：Accepted
- 日期：2026-11-25
- 适用范围：Phase 1 Task 1.7

## 背景

订单提交与进入模拟市场之间需要可配置延迟。延迟期间行情可能变化，市价买单若继续使用提交时价格估算而无预算上限，可能透支账户；若复用活动挂单状态，又无法可靠区分尚未入场和已经入场的订单。

## 决策

1. 完成校验及资金冻结、尚未进入市场的订单使用 `PENDING_EXECUTION`。
2. 到达预定执行时间后才读取当时已接收并处理的有效订单簿。
3. 延迟市价买单必须显式提供最大计价资产预算，预算包含成交金额及 Taker Fee。
4. 撮合逐档按价格顺序进行，成交量按交易所 quantity increment 向下调整，并满足最小数量及最小金额。
5. 预算或流动性不足时，在合法范围内部分成交，随后取消剩余数量并释放剩余冻结资金。
6. 不使用账户其他可用余额追加预算，不自动扩大冻结额。
7. GTC 限价单到期后的未成交部分进入活动挂单，不采用市价单的自动取消规则。
8. 无效、过期、断线或未来行情导致尚未入场订单终止，并记录 `MARKET_DATA_UNAVAILABLE`。
9. Clock 可替换；核心领域不使用 `sleep`。同一预定时间按确定性订单序列执行。

## 结果

- 延迟价格上涨不会导致负余额或隐式追加预算。
- `PENDING_EXECUTION` 与活动 GTC 挂单的语义明确分离。
- ManualClock 可无真实等待地覆盖延迟、取消和事件顺序测试。
- 本模型是模拟实验参数，不代表交易所或网络的真实延迟。
